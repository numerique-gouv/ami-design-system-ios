# AMI Design System for iOS

This repository is the entry point for the AMI Design System for iOS.

## The main content

This design system is based on DSFR: <https://www.systeme-de-design.gouv.fr/version-courante/fr>

This AMI Design System currently provides:
- a set of named colors
- a set of named icons
- a set of Marianne font variants

This repository contains:
- a Swift Package in folder `AmiDesignSystem`
- an example project named `AMI-design-system-lab-xcodegen` in folder `Examples`

## The `AmiDesignSystem` Swift Package

### How to build the Swift Package
```sh
    cd AmiDesignSystem
    swift build
```

The Swift Package project uses `SwiftGen` plugin (<https://github.com/SwiftGen/SwiftGenPlugin>) to generate at build time Swift classes with hierarchical content:
- AmiDesignSystem.Colors
- AmiDesignSystem.Icons

### What to find in the Swift Package

AmiDesignSystem exposes assets of types:
- DsfrColorAsset
- DsfrImageAsset

To access **SwiftUI colors** and Images, you use:
- <myDsfrColorAsset>.swiftUIColor
- <myDsfrImageAsset>.swiftUIImage

To access **UIKit colors** and Images, you use:
- <myDsfrColorAsset>.color
- <myDsfrImageAsset>.image

AmiDesignSystem gives you access to Marianne fonts for several usages.

Theses usages are listed in an `Enum`:
```swift
    public enum DsfrFont {
        case h1, h2, h3, h4, h5, h6
        case textXL, textLG, textMD, textSM, textXS
    }
```

You use it on a Text using a SwiftUI modifier:
```swift
    Text(fontItem.typeLabel)
        .dsfrFont(fontItem.font)
```
    
## Using `AmiDesignSystem` Swift Package in your product

To use `AmiDesignSystem` Swift Package in your Xcode project, just import it using menu `File > Add Package Dependencies…` and paste the repository url: <https://github.com/numerique-gouv/ami-design-system-ios/AmiDesignSystem/>

Then, in your Xcode source files, import the module and use it:
```swift
    import AmiDesignSystem
    
    let titleColorAsset = AmiDesignSystem.Colors.Text.Title.blueFrance
    let partnerIconAsset = AmiDesignSystem.Icons.Ami.Services.demarcheNumeriqueGouvFr
```
    
## The `AMI-design-system-lab-xcodegen` sample

The sample application is located in `Examples` folder.

To prepare the sample application Xcode project, you need `xcodegen` tool (install it via terminal command `brew install xcodegen`).

```shell
    cd Examples
    xcodegen generate --spec ami-design-system-lab-project.yml
```

> **Note**: the first time you checkout the project, you must to generate the project once, then build it (it will failed because of missing files in`Generated` subfolder). The missing files are generated by this first build. You must generate the project a second time (the files in Generated will be included in the project this time) and then you can build the Xcode project successfully.

This will generate the `AMI-design-system-lab-xcodegen.xcodeproj` Xcode project strucutre.

The `AMI-design-system-lab-xcodegen.xcodeproj` links to `AmiDesignSystem` Szwift Package (locally).

Then, you can run it using Xcode in Simulator or real device.
